## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2025-05-22 - Visual Feedback in Level Menus
**Learning:** Difficulty-based color coding and interactive states (hover/active) in level selection provide immediate visual context and tactile feedback, making the UI feel more responsive and intuitive.
**Action:** Implement consistent color systems for difficulty and ensure all interactive elements have distinct hover and active states.
