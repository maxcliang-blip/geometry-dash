## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-06-18 - Visual Affordance and Focus States
**Learning:** Adding difficulty-based color coding and custom focus-visible styles significantly improves visual categorization and keyboard accessibility for game level selection.
**Action:** Use specific color palettes for difficulty levels and ensure high-contrast focus indicators are present for all interactive elements.
