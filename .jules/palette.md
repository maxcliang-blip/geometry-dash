## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-18 - Visual Affordance for Game Controls
**Learning:** Representing keyboard shortcuts using semantic `<kbd>` elements styled to look like physical keys provides a strong visual affordance that makes game controls instantly recognizable and more intuitive than plain text.
**Action:** Always use `<kbd>` tags for keyboard controls and apply "physical key" styling (borders, shadows) to enhance discoverability.
