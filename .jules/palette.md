## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-20 - Tactile Keyboard Instructions
**Learning:** Using `<kbd>` tags paired with "physical key" CSS styling (e.g., `border-bottom` for depth) provides a clear mental model for keyboard-driven interactions, making instructions significantly more intuitive than plain text.
**Action:** Utilize `<kbd>` with depth-focused styling for all keyboard control documentation to enhance user intuition.
