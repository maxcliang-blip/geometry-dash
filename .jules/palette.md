## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-19 - Keyboard Accessibility in Custom Menus
**Learning:** Custom-styled buttons often lose their default focus indicators. Explicitly defining `:focus-visible` styles ensures keyboard users have clear visual feedback without affecting mouse users.
**Action:** Always include high-visibility `:focus-visible` outlines for interactive elements when applying custom background colors or removing default borders.
