## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-05-22 - Visual Hierarchy via Difficulty Categorization
**Learning:** Color-coding level buttons by difficulty (Easy/Blue, Hard/Red, Demon/Purple) provides an immediate visual cue that reduces cognitive load when making a selection. Combining this with glassmorphism (backdrop-filter) creates a focused, high-contrast UI that feels integrated with the game's aesthetic.
**Action:** Use a consistent color palette for difficulty tiers and ensure interactive elements have clear, elevated hover and focus states for both visual and keyboard-based feedback.
