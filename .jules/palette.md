## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-19 - Tactile and Accessible Controls
**Learning:** Using `<kbd>` tags for keyboard control hints and `:focus-visible` for focus states provides a clear, tactile interface that remains aesthetically clean for mouse users while being fully accessible for keyboard users.
**Action:** Combine semantic key representation with targeted focus styles to balance visual design and accessibility.
