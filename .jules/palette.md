## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-05-13 - Visual Keyboard Hints
**Learning:** Using `<kbd>` tags combined with physical 'key' styling (border, shadow, and background contrast) provides immediate visual affordance for keyboard controls, making them more intuitive than plain text.
**Action:** Use semantic `<kbd>` tags with dedicated CSS for any keyboard-based control instructions.
