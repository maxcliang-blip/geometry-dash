## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2024-05-09 - Tactile Feedback in Game Menus
**Learning:** Adding `transform: translateY` on `:hover` and `:active` states for buttons creates a "physical" feel that is particularly important for game UIs to feel responsive and high-quality.
**Action:** Use CSS transforms and transitions to provide immediate tactile feedback for all interactive game elements.
