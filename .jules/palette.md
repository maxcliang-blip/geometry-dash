## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-19 - Semantic Keyboard Instructions
**Learning:** Utilizing `<kbd>` tags for keyboard control instructions provides both semantic meaning for assistive technologies and a clear visual hook for styling physical-looking keys.
**Action:** Use `<kbd>` for all keyboard-related instructions to improve both accessibility and visual clarity.
