## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-18 - Visual Categorization of Difficulty
**Learning:** Color-coding level selection buttons by difficulty (e.g., Blue for Easy, Red for Hard, Purple for Demon) provides immediate visual affordance and helps users categorize choices faster.
**Action:** Use distinct, meaningful color schemes for hierarchical or categorized interactive elements to reduce cognitive load.
