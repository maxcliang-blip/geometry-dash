## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-05-22 - Tactical Key Visualization
**Learning:** Using `<kbd>` tags with physical key styling (border-bottom shadow and monospaced font) significantly increases the discoverability of keyboard controls and provides a more tactile feel to technical instructions.
**Action:** Use `<kbd>` tags for all keyboard shortcuts in UI hints to improve both semantics and visual intuition.
