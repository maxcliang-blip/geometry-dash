## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-18 - Centered Menu and Interactive Feedback
**Learning:** Centering the main menu and adding clear visual feedback (colors and hover effects) for level selection significantly improves the first-time user experience and perceived quality.
**Action:** Use absolute centering for menus and provide distinct colors for difficulty levels to aid quick recognition.
