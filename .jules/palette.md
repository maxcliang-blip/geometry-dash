## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-18 - Difficulty Color Coding
**Learning:** Color-coding level buttons by difficulty (e.g., green for easy, orange for hard, purple for demon) provides instant visual feedback that complements text labels, helping users quickly identify appropriate challenges.
**Action:** Use a consistent color palette for difficulty levels across the application's UI.
