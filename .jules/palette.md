## 2026-04-18 - Semantic Level Selection
**Learning:** Using a `<nav>` with `aria-label` for level selection improves screen reader navigation by clearly identifying the navigation landmark and its purpose.
**Action:** Always wrap menu-like button groups in semantic navigation elements with descriptive labels.

## 2026-04-18 - Visual Affordance for Keyboard Controls
**Learning:** Styling `<kbd>` tags with a physical 'key' appearance (borders, shadows, and subtle background contrast) provides a strong visual affordance that helps users quickly identify keyboard shortcuts.
**Action:** Use semantic `<kbd>` tags for control hints and apply consistent physical key styling across the UI.
